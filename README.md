# Northstar Investment Watchlist

Northstar is a personal tracker for organizing investments you want to follow, recording your own quotes and unit counts, and keeping price targets close at hand.

## What it includes

- A watchlist for stocks, ETFs, mutual funds, and gold.
- Manually entered units, last price, daily change, and optional target.
- Summary values calculated from saved units and quotes.
- All, Stocks, Funds, and Starred filters with search.
- Star and unstar controls, target status labels, and a confirmation dialog for removal.
- Indian rupee formatting and responsive layout.

## How to use it

Review the sample watchlist or add an asset with its symbol, name, type, units, quote, daily percentage move, and optional target. Use the tabs or search to narrow the list. Select the star to keep an asset in Starred. Use the delete button to remove an entry after confirmation.

## Quotes and data

Sample quotes are illustrative and are not live market data. Update values yourself using information from your brokerage or a trusted provider. The totals multiply each saved quote by the number of units entered. Watchlist entries are saved in this browser's local storage and are not synced to an account.

## Run locally

Run npm install to install dependencies, npm run dev to start the local server, npm run lint and npm run build to check the project, and npm run deploy to publish it to GitHub Pages.

Planned URL after deployment: https://a2rp.github.io/investment-watchlist/

## Future improvements

Ideas that are not implemented yet: a trusted market-data connection, price-alert notifications, and CSV import/export.
